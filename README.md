# 🏠 California Housing Price Prediction

A Machine Learning project that predicts **California district housing values** using regression algorithms. The project uses the **California Housing dataset** from Scikit-learn and compares Linear Regression with Random Forest Regression.

The trained Random Forest model is saved using Pickle and deployed through a **FastAPI REST API** for making predictions.

## 📌 Project Overview

This project demonstrates an end-to-end Machine Learning workflow:

* Loading the California Housing dataset
* Preparing features and target values
* Creating a Pandas DataFrame
* Splitting data into training and testing sets
* Training a Linear Regression model
* Training a Random Forest Regression model
* Comparing model performance
* Making housing value predictions
* Saving the trained model using Pickle
* Deploying the model using FastAPI

The dataset contains **20,640 instances and 8 predictive features**. The target represents the median house value for California districts.

## 📊 Dataset

The project uses:

**California Housing Dataset**

It is loaded directly using:

```python
from sklearn.datasets import fetch_california_housing

housing = fetch_california_housing()
```

### Features

| Feature      | Description                              |
| ------------ | ---------------------------------------- |
| `MedInc`     | Median income in the block group         |
| `HouseAge`   | Median house age                         |
| `AveRooms`   | Average number of rooms per household    |
| `AveBedrms`  | Average number of bedrooms per household |
| `Population` | Block group population                   |
| `AveOccup`   | Average number of household members      |
| `Latitude`   | Block group latitude                     |
| `Longitude`  | Block group longitude                    |

The notebook uses all eight features as input variables.

### Target

The target variable is:

```text
MedHouseVal
```

It represents the median house value for California districts, expressed in hundreds of thousands of dollars.

## 🤖 Machine Learning Models

### 1. Linear Regression

The project first trains a Linear Regression model:

```python
from sklearn.linear_model import LinearRegression

reg = LinearRegression()
reg.fit(X_train, y_train)
```

The recorded scores were:

* Training Score: **0.6034**
* Testing Score: **0.6278**

### 2. Random Forest Regression

A Random Forest Regressor is then trained using 111 estimators:

```python
from sklearn.ensemble import RandomForestRegressor

rfr = RandomForestRegressor(n_estimators=111)
rfr.fit(X_train, y_train)
```

Recorded scores:

* Training Score: **0.9736**
* Testing Score: **0.8380**

Based on the recorded test scores, the **Random Forest model performed better** than Linear Regression on this project.

## 🔀 Train-Test Split

The dataset is divided into training and testing data using:

```python
train_test_split(
    data,
    target,
    test_size=0.1,
    random_state=66
)
```

This means 10% of the data is used for testing.

## 🔮 Prediction Example

The Random Forest model is tested with the following input:

```python
[
    [8.32, 41.0, 6.98, 1.023, 322.0, 2.55, 37.88, -122.23]
]
```

The recorded prediction is approximately:

```text
4.3391
```

## 💾 Model Saving

After training, the Random Forest model is saved as:

```python
import pickle

pickle.dump(rfr, open("regressor.pkl", "wb"))
```

The saved model can later be loaded without retraining:

```python
model = pickle.load(open("regressor.pkl", "rb"))
```

## 🚀 FastAPI Deployment

The trained model is deployed using **FastAPI**.

The API loads the saved `regressor.pkl` model and provides a `/predict` endpoint.

### API Endpoint

```text
POST /predict
```

### Input Parameters

```text
MedInc
HouseAge
AveRooms
AveBedrms
Population
AveOccup
Latitude
Longitude
```

### Example JSON Input

```json
{
  "MedInc": 8.3252,
  "HouseAge": 41,
  "AveRooms": 6.984127,
  "AveBedrms": 1.023810,
  "Population": 322,
  "AveOccup": 2.555556,
  "Latitude": 37.88,
  "Longitude": -122.23
}
```

These values correspond to the input format used in the notebook/API.

### API Response

The API returns the predicted value in the following format:

```json
{
  "prediction": 4.3391
}
```

The FastAPI implementation returns the model prediction under the `prediction` key.
